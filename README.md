# dsh-health-assistant 🧘

**健康小助手** —— 提醒你在用 DeepSeek Harness 时科学作息。

| 提醒 | 默认触发 |
|---|---|
| 休息 | 专注满 **30 分钟** → 起来走 5 分钟 |
| 劝停（第一档） | 连续工作 **2 小时** → 活动 10 分钟 |
| 劝停（第二档） | 连续工作 **4 小时** → 建议收尾、离开屏幕 |
| 熬夜 | **23:00–06:00** 期间每 30 分钟提醒一次 |

全部可调，全部可关。

## 它怎么判断「你在工作」

- 页面**可见**，且最近 **5 分钟**内有操作（点击 / 键盘 / 滚轮）才算；
- 离开超过 5 分钟 → 视为已休息，专注计时清零；
- 只累计真实专注的时间，不按挂机算。

## 界面

- **右下角浮层**：到点弹出，20 秒后自动收起（悬停暂停倒数），三个选择 —— `休息一下` / `10 分钟后再提醒` / `今天不再提醒`
- **输入框下方一行**：`🧘 1 小时 20 分`（本次专注时长），静默时变灰
- **设置 → 健康助手**：间隔、两档劝停、熬夜时段、总开关、恢复默认

## 两个可选开关

| 开关 | 默认 | 作用 |
|---|---|---|
| **后台也计时** | 关 | 切到别的应用时继续计时。关着的时候「看不见 = 你在休息」 |
| **系统通知** | 关 | 需要浏览器授权；开启后即使 DSH 在后台也会弹系统通知。授权状态由浏览器记忆 |

## 隐私

**完全本地。** 计时、设置、静默状态都只在浏览器 `localStorage`（键前缀 `dsh-health:`），
不联网、不上报、不收集任何数据。

## 安装

```bash
dsh plugin add dsh-health-assistant
```

或在 profile 的 `cordis.patch.yml` 里插入：

```yaml
- insert:
    - id: dsh-health-assistant
      name: 'dsh-health-assistant'
```

## 设计取舍

- **不弹系统通知**：浏览器通知需要授权，且容易变成打扰。浮层挂在页面内，看得见就够。
- **不催第二次**：同一档长时提醒只触发一次，劝停失败也不连环轰炸。
- **关掉页面就停**：提醒是「你在用的时候才提醒你」，不在后台计时。
